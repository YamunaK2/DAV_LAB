# Data Analytics and Visualization Lab

This repository contains the programs and Jupyter Notebooks for the **Data Analytics and Visualization Laboratory**.

## Experiments

| Experiment | Topic |
|------------|-------|
| Exp 1 | Installation and Exploration of NumPy, SciPy, Jupyter, Statsmodels, Pandas, Matplotlib, Seaborn, Plotly and Bokeh |
| Exp 2 | Working with NumPy Arrays |
| Exp 3 | Working with Pandas DataFrames |
| Exp 4 | Reading Data from Text Files, Excel and the Web |
| Exp 5 | Descriptive Analytics using the Iris Dataset |
| Exp 6 | Univariate Analysis using Diabetes Datasets |
| Exp 7 | Bivariate Analysis – Linear and Logistic Regression |
| Exp 8 | Multiple Regression Analysis |
| Exp 9 | Comparison of Analysis Results between UCI and Pima Indians Diabetes Datasets |
| Exp 10 | Data Visualization – Normal Curves |
| Exp 11 | Hypothesis Testing – Z-Test |
| Exp 12 | T-Test on Diabetes Datasets |
| Exp 13 | ANOVA on Diabetes Datasets |
| Exp 14 | Building and Validating Linear Models |
| Exp 15 | Building and Validating Logistic Models |
| Exp 16 | Time Series Analysis |

## Technologies Used
